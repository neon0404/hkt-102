# AI-маркетолог

Сервис ведёт Telegram-канал компании. Задачи принимаются в Telegram обычным языком, текстом или голосом. По материалам компании сервис готовит пост с карточкой, отправляет его на согласование и публикует только после одобрения. Копия поста уходит во ВКонтакте. Регулярные задачи — черновики, контент-план, отчёты, мониторинг сайта, сбор метрик — выполняются по расписанию. Один оператор ведёт несколько независимых компаний.

Прототип для хакатона «Кибер 102», кейс АО «Салаватстекло».

## Возможности

- посты по базе знаний компании с источниками фактов, карточка по макетам брендбука, журнальный формат с каруселью фото;
- согласование кнопками, словами или голосом, ручная отправка и перенос времени выхода;
- контент-план на неделю, отчёты с просмотрами, реакциями и переходами;
- короткие видео 9:16 из фото компании с субтитрами и голосом диктора;
- публикация в Telegram-канал и сообщество ВКонтакте;
- админка оператора: компании, источники, профиль бренда, каналы, расписания, журналы, расход;
- Telegram Mini App для клиента и согласующего;
- MCP-сервер `/mcp` для внешних агентов (Claude Code, Claude Desktop, Cursor).

## Стек

- `app/` — Nuxt 4 + Nuxt UI 4: админка и Telegram Mini App;
- `server/` — Nitro: REST API, MCP-сервер, короткие ссылки для учёта переходов;
- `worker/` — бот на grammY, планировщик и очередь задач;
- `core/` — общий код: БД на Drizzle и PostgreSQL, модель через Codex CLI или OpenAI-совместимый API, карточки на `@napi-rs/canvas`, видео на ffmpeg;
- деплой — Docker Compose.

## Запуск

```bash
pnpm install
cp .env.example .env
docker compose -f docker-compose.dev.yml up -d
pnpm db:migrate
pnpm dev        # админка: http://localhost:3000
pnpm worker     # бот, планировщик, задачи
```

Продакшен: `docker compose up -d --build`.
